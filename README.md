# MatchedGFormula

***0_regularizedParameterSetup.R***: Set parameters, including number of time points, coefficients. There are 3 different setups. (need to input $\texttt{set}$ = 1,2,3).

***1_regularizedTrueACE.R***: Use sampling to get the true risks under always treatment / never treatment.

***2_regularizedDataGenerating.R***: Generate data.

***3_regularizedDataFitting.R***: Fitting with regularization for the 4 methods.

***3_dataFitting.R***: Fitting without regularization for the 4 methods.
